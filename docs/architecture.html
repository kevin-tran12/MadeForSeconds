Cloud Infrastructure Map

Google Cloud (us-central1) for compute, data, and auth; Cloudflare Pages for the static frontend. Everything on the GCP side is defined in terraform/ across five modules — security, storage, backend‑service, observability, cost‑controls. One fact drives most of the shape below: a single Cloud Run service is the hub — it is the only compute that touches Firestore, all three buckets, Secret Manager, and every third‑party API. Cloudflare only ever serves static files.
